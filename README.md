## Yuliia Kulykivska

Principal AI & Full Stack Engineer at [Shmoozer](https://shmoozer.com) · Founder & ML Engineer at [RaceModel](https://racemodel.io) · Chicago

I build machine learning systems that have to be right in production, and the tooling that keeps them that way.

**RaceModel** — race outcome prediction for F1, IndyCar and NASCAR: finishing positions, DNF probabilities, strategy simulation. XGBoost on tabular telemetry and historical results, served through a FastAPI + Postgres + Redis stack with embeddable widgets.

**Shmoozer** — realtime companion platform: payouts, socket delivery across pods, load and security work on a Kubernetes/AWS footprint.
